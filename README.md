# LLMaestro

Orchestration of multi-LLM AI agents, cloud and local. LLMaestro routes tasks
to different providers (OpenCode, Cerebras, Groq, local Ollama) according to
need, with automatic fallback, tool use, and vision / computer-use support.

Work in progress.

## Stack

- Python
- LLM providers and SDKs (cloud and local)
